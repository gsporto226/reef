# Typed links in one link tree, with arguments in history and guards over windowing

Issue #57 needs reef to support a browser-like app. Links are declared once as
typed route values in a **link tree**. Navigation and **guards** are built on
the windowing commands that already exist. Query arguments are stored in the
doc. This supersedes parts of spec §9
(`packages/reef/docs/specs/2026-09-02-windowing-design.md`): the untyped link
table, arguments that only reach the link policy, and browser back and forward
opening the URL as a new link. ADR 0003 still holds. reef uses Flutter's route
information API and no third-party router, and windowing builds the pages.

## Decisions

### Doc model and history

- **Arguments live in history entries (D1).** Each back, current and forward
  slot is `(buffer, arguments, entry id)`. When old hibernation records are
  read, a bare buffer id string loads with empty arguments, so no migration
  is needed. ~~Matching an open window compares the buffer only, because
  arguments are page state, not identity.~~ Superseded by ADR 0005.
- **Browser back and forward use a stable entry id (D2).** The route
  information state holds the history entry's id. On popstate, reef focuses
  the window that owns the entry and moves its history to that entry. If the
  entry no longer exists, reef opens the URL as a link. Other platforms use
  the URL only.
- **Fresh links are set in three layers (D3).** The tree sets the default
  (`false`), a link can override it, and a call site can override both. The
  most specific setting wins. A fresh buffer adds a UUID v7 that is not part
  of the URL. Going to a fresh link pushes into the focused window, because a
  fresh buffer is never already open. This replaces the link table's
  `drafts` set.
- **The buffer kind is always derived from the mounted path (D4).** Renaming
  a path invalidates saved buffers for it, as it would break old browser
  links. A restored buffer whose kind no longer resolves opens the
  not-found route and does not throw.

### Links and the tree

- **Home mounts at `/`, and not-found is a catch-all link (D6).** A rest
  segment (`/**`) ranks below every concrete link, so not-found is a typed
  route with guards and the unmatched path. A catch-all scoped under a parent
  gives a scoped not-found. `LinkTree` has no `notFound` parameter. A tree
  without a root catch-all fails at startup. There are no URL rewrites or
  alias links.
- **One link has one mount (D12).** A link mounted twice fails at startup. To
  show the same page under two parents, use two route types.
- **Rest parents can have children (D13).** Child segments match from the end
  of the URL, and the child wins. With `/files/**` and `/files/**/edit`, a
  file named `edit` can't be opened.
- **Query is one flat bag per URL, and children inherit it (D14).** The child
  route holds its parent value, so the child URL carries the parent's query,
  and decoding the URL gives back the same route. A child that redeclares an
  inherited key fails at startup; it reads the value from its parent. This
  follows TanStack Router. Spike:
  `packages/reef_router/spike/d14_inherited_query.dart`.
- **Every query has a required fallback (D15).** For a nullable value, write
  `.query<V?>(…, fallback: null)`. A value that must be present belongs in
  the path. A fallback value is left out of the URL.
- **The parent is the first constructor parameter (D20).** The compiler
  enforces this through `.build`.
- **The arity cap is 20 (D21).** reef is a library, so apps can't raise the
  cap. The arities are generated by a script and committed, and CI reruns the
  script and fails on a diff.
- **Segments have no names (D16), and there is no round-trip helper (D5).**
  The compiler can't catch two same-typed parts given in the wrong order. Use
  distinct id types where a link has two parts of the same type.

### Guards

- **Guards are synchronous (D9).** Windowing's interceptor decides before the
  reducer runs. Server checks belong in the page's loading state.
- **Destination and environment types are checked at bind (D10).** Bind runs
  before the first frame, so a mismatch fails at app start. There is no
  compile-time check.
- **`.guard` takes an optional `name:` for errors (D11).** The route is parsed
  from the buffer id for every command, with no cache (D23).
- **A redirect replaces the guarded entry (D7).** Back from the redirect
  target then skips the guarded page. Pushing the target on top would bounce
  the user back into the redirect.
- **Guards re-run without a navigation (D8).** The environment exposes a
  `Listenable`, and the bound tree re-checks the visible buffers when it
  fires. Restore runs the same re-check, and so do undo and redo, which skip
  the interceptor (`WindowingController.interceptor`). A redirect from a
  re-check replaces the entry.

### Navigation and URL sync

- **go stays as the link policy decides (D22).** Fresh links give
  "follow the link in the current tab" behaviour. Push and replace with no
  focused window fall back to go.
- **`LinkTable` is deleted (D19)** in the change that moves the controller
  and URL sync to the link tree.
- **There is no navigation queue (D24).** The existing echo counter in
  `WindowingLinkSync` is enough while every verb except a new window is
  synchronous.
- **Page transitions are in scope (D18).** Windowing's page builder takes a
  transition hook, chosen per route type. This changes windowing, not links.
- **Layout state stays out of the URL (D17).** Spec §9 holds: the URL owns
  content, and hibernation owns layout.

## Considered options

- **A side map from buffer to its latest arguments (D1).** Rejected: the same
  buffer at two points in the back stack, with different queries, would show
  the latest query at both.
- **A window id plus an index as the history state (D2).** Rejected: the
  index shifts when an entry is replaced.
- **Separate parent and child queries, or a child URL without the parent's
  query (D14).** Rejected: no router does either, and the second can't decode
  the URL back to the same route.
- **Pushing the redirect target on top of the guarded entry (D7).**
  Rejected: back from the target returns to the guarded page, which
  redirects again.

## Consequences

- `BufferHistory` and its serialised form change, and every reader of
  `.current` as a `BufferId` moves to the entry.
- A URL rename invalidates saved sessions for that path, and this is
  intentional.
- Research on routefly, duck_router, navigation_utils, typed_go_router and
  octopus's `bucket_navigator` was skipped (D25).
